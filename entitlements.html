1. 4-Tier Entitlement Availability Taxonomy

  • Private to Apple (114) com.apple.private.* and internal system entitlements (com.apple.QuartzCore.*, com.apple.runningboard.*, com.apple.tcc.delegated-services, aps-connection-initiate) granted exclusively to Apple-signed platform binaries.
  • BrowserEngineKit (6) The 6 entitlements documented for third-party browser engines on iOS (com.apple.developer.web-browser-engine.{host,webcontent,rendering,networking}, restrict.notifyd, and com.apple.developer.cs.allow-jit).
  • Restricted Other (20) Managed capabilities requiring separate Apple approval outside BrowserEngineKit (e.g., com.apple.developer.web-browser, embedded-web-browser-engine, group-session, in-app-identity-presentment) or App Sandbox temporary exceptions.
  • Generally Available (19) Standard public entitlements available to any Apple Developer account in Xcode (e.g., increased-memory-limit, extended-virtual-addressing, hardened-process, keychain-access-groups).

2. How WebKit Signs iOS Processes vs. 3P BrowserEngineKit

  • Static .entitlements Plists Source/WebKit/UIProcess/AuxiliaryProcessExtensions/*.entitlements define the baseline BrowserEngineKit plists (2–6 keys per extension) used on iOS Simulator or open-source builds.
  • process-entitlements.sh (iphoneos) When built by Apple with WK_USE_RESTRICTED_ENTITLEMENTS=YES, Source/WebKit/Scripts/process-entitlements.sh dynamically injects ~60 private entitlements into WebContent (28), GPU (31), Networking (25), webpushd (12), adattributiond (4), and ModelProcess (6).
  • Runtime & Seatbelt Checks WebKit's UIProcess, NetworkProcess, and Seatbelt profiles (require-entitlement) actively inspect caller/host entitlements via WTF::hasEntitlement() to gate privileged IPC endpoints, JIT flags, and sandbox extensions.

3. iOS Competitive Parity Status Tiers

  • iOS WebKit-Exclusive (84) Active on iOS production WebKit processes or checked on iOS host apps, but unavailable to 3P BrowserEngineKit browsers (82 Apple-private + 2 restricted-other).
  • BrowserEngineKit Granted (6) Explicitly granted to 3P browser engine extensions and host apps under BrowserEngineKit.
  • iOS Managed Approval (3) Requires separate Apple developer approval on iOS (Default Browser, GroupActivities, IdentityDocumentServices).
  • iOS Public Parity (7) Public iOS entitlements any developer can enable (extended virtual addressing, hardened-process, app-groups).
  • macOS / Test Harness Only (59) Used only on macOS (mac_process_*, App Sandbox) or internal WebKit test runners (DumpRenderTree, WebKitTestRunner).
